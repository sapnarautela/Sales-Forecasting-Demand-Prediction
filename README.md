# Sales Forecasting & Demand Prediction Analysis

## Project Overview
This project focuses on analyzing historical sales data and forecasting future sales to support business planning and inventory management.

## Objectives
- Analyze historical sales trends.
- Forecast future sales based on previous sales patterns.
- Compare actual sales with forecasted sales.
- Identify demand patterns.
- Support inventory and business planning.

## Tools & Technologies
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Sales Forecasting
- Data Visualization

## Project Features
- Historical sales analysis
- Actual vs. forecast sales comparison
- Monthly sales forecasting
- Demand trend analysis

## Project File
`Sales_Forecasting_Demand_Analysis.xlsx`

## Project Outcome
Developed an Excel-based sales forecasting analysis to understand sales trends, estimate future demand, and support data-driven business decisions.
